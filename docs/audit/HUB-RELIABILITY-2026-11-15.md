## Remaining gaps / gates, ordered for continuation

1. **High severity: private collector serialization.** Worker cron and GitHub may still observe one account concurrently; an in-flight poll can race opt-out. Existing tombstones protect later enrolment, but do not prove atomic write fencing or exactly-once deltas. Resolve using a locally proven account-level serialization/consent fence across BOTH writers, then separately validate rollout/rollback with aggregate-only D1 access. This PR does not introduce a speculative live migration or claim that race is fixed.
2. **Physical Android acceptance.** Native file picker/export (including compressed/large round trips), back gesture, repeated rotation with keyboard/picker open, renderer/process death, real background/resume, persistent device data, and cold/warm latency/heap remain unverified. The local `adb` probe could not initialize its read-only home directory; no device test or installation occurred. Browser viewport/lifecycle notifications are explicitly synthetic.
3. **Preview cloud-monitor boundary.** The APK retains the existing preview origin and separate package. The Worker intentionally permits only the production origin. The preview can exercise the existing GW2 local engine and account API, but private monitor integration must be separately accepted; no CORS/origin migration is silently performed. Original production collectors remain untouched.
4. **Standalone Golden Exchange v4 parity.** Tax assumptions/actual tax, FIFO, stable merge IDs, windowed limits, research/watch/search/chart and recovery are improved. Still absent: v4 transactional personal-state IndexedDB, full v3 backup migration (including tickets/owned/adjustments/audit), correction audit UI, paper research tickets and slot/held-stock/reserve-aware multi-item allocation, comparison/error-sensitivity tools and some detailed risk settings. Do not import a v4 backup into this simpler format by dropping fields. Existing importer explicitly rejects unsupported formats. Keep the standalone app installed.
5. **Live account and forecast evidence.** No actual private D1 readback, closed-phone continuity, complete pre-90-day basis or genuine held-out prospective buy→resale study was available. Existing forecasts remain uncalibrated/research-gated, with promotion disabled. Do not infer this evidence from a green CI run.
6. **Production/security readiness.** APK remains debug-signed, min26/target34. Modern target/insets acceptance and owner-controlled release signing are prerequisites for a store build. Five lint warnings are disclosed, not suppressed. Remote dependency/third-party policy rights are not newly certified by this reliability audit.
