# Golden Peanut — systems, intelligence and performance audit
**Checkpoint:** 15 November 2026 · connected GitHub source audit, current main + review PR #42

## Audit confidence

This review inspects source code, existing engineering evidence and the synthetic GitHub CI tests. It has **not** authenticated to a real GW2 account, queried private D1 tables, measured on a physical Galaxy S23 Ultra or verified public Pages asset hashes. A passing browser test proves the mocked integration, not real account continuity, market fills or projected profits. Do not describe all findings as production-verified.

## Confirmed defects or costs, with evidence

**P8-101 · HIGH · Startup payload overfetch.** The source starts `GPMarketFeed.load(State)`, a complete ~15.7 MB JSON dataset that contains far more than the names/type/rarity needed for initial labels. Every request used `cache:'no-store'`. **PR #42:** complete, validated index for startup, named no-trade-data, full-data fallback, conditional revalidation. Collector must publish the new index before improvement occurs on devices.

**P8-102 · HIGH · Single-item chart payload overfetch.** An item chart previously used `loadHistory()`, a ~6.6 MB complete 21-day bid/ask snapshot. **PR #42:** deterministic 32 slices preserving every history entry and generation, one-shard chart loading, coalesced concurrent calls, full-feed fallback. No invented traded volume.

**P8-103 · MEDIUM · Search caused synchronous repeated DOM destruction.** `#focus-trade-search` and `#focus-order-search` input handlers immediately ran `renderTrades`/`renderOrders`. **PR #42:** 130ms event coalescing and Enter shortcut, preserving the last input, all results and exact user query.

**P8-104 · MEDIUM · Guided screen reallocated/sorted on routine repaint.** The guided `ideas()` path invoked `GPMarketBoard.build` for every navigation and refresh even if the same plan was displayed. **PR #42:** minute-bounded, revision-aware cache keyed on account, wallet, plan arrays/lengths, latest opportunity stamp, market-index status and engine identity. Full results are still reconsidered at a new minute, account/plan revision or explicit refresh. Add browser regression for rebuild counts.

**P9-101 · CONFIRMED, RESOLVED IN MAIN.** Redundant Skip, saved skipped-items state and explanatory notes. PR #41 removes the action, UI and state; Previous/Next only. No model or ledger changes.

**P8-105 · CONFIRMED, RESOLVED IN MAIN.** Visible capital funding input could be replaced by background repaint while typing (500g reverted to 819g in an initial CI run). PR #41 preserves the focused budget during automatic redraw; subsequent full CI passed.

**P0-002 · HIGH, OPEN.** `7.16.0-evidence` build stamp persists in HTML, multiple JS modules and `scripts/check_release.py`; several newer front-end revisions use cache-bust query tags. Existing `pages-production.yml` validates the old substring rather than an exact built commit. Two production deployment workflows exist, and `pages-preview.yml` still pins a stale development branch. A green upload must not be mistaken for verified production asset identity. Consolidate production workflows *after* validated rollback and exact served-asset checks; do not blindly delete either one.

**P2-001 · CRITICAL TO FORECAST TRUST, UNVERIFIED LIVE.** The GitHub private collector + D1 + Worker + local event ingestion exists and is partially regression tested, but no authenticated latest collector run, persisted D1 event count, or physical closed-phone replay was independently observed in this audit. A sleeping phone cannot be credited with all observation windows without that proof.

**P1/P5/P7 · CRITICAL TO FORECAST TRUST, UNVERIFIED LIVE.** Strict forecasts need complete cohort provenance, competitive positioning, censoring and zero inclusive windows, chronological holdout evaluation, and wallet/inventory conservation. The engine deliberately withholds unsupported predictions; don't manufacture missing links or promote public standing quantities to fills.

**P10-001 · OPEN.** The live API adapter accepts the key in the ArenaNet URL query in parts of `app/index.html`. This should receive a separate authorization/header migration and compatibility test rather than an untested authentication rewrite. Inspect remote telemetry/third-party referrer paths; the client requests use no-referrer in the public adapter. No secrets were intentionally committed by this audit.

## Cleanup boundaries

- **Removed:** redundant guided Skip button/action/state, orphan Skip CSS, and unnecessary active-input panel rebuild (merged PR #41).
- **Retained on purpose:** original full public quotes/history/recipes/depth, IndexedDB ledger and account-specific keys, backup/export, execution model, potentially important draft diagnostic branches, and fallback loaders. They are not disposable merely because they're large.
- **Review before any destructive deletion:** the large legacy allocator/desk embedded in `app/index.html`, duplicate deployment workflows, stale documentation, old version markers and old public datasets. Some remain useful for data migration, resilience or diagnostics. Deleting them without differential browser tests risks silent loss of intelligence.
- **Do not claim:** dramatically faster device startup, complete D1 synchronization or model profit uplift until a controlled physical and live-data study verifies each claim.

## Regression gates and measurements

Source/schema/credential guard: `python scripts/check_release.py`.
Unit: `npm test` (execution, market board, public feed, private monitor, capital, stress, startup and guided deck).
Python: `python -m unittest discover -s tests -p 'test_*.py'`.
Assembled 1440px/390px Chromium: `npm run test:browser`.
Public generations: count, dedup, IDs, quote freshness and row/shard parity; a partial generation must fail closed.
Performance claim: measure repeated cold/warm page loads, HTTP request bytes, elapsed stage times, IndexedDB reads/writes, DOM counts, search latency, charts, Android Back and memory; compare median/p95 under equal conditions; include physical phone separately. Neither source size alone nor a green CI run proves the final speed-up.
